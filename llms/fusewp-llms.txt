# FuseWP

> FuseWP is a WordPress automation plugin that synchronizes WordPress users, ecommerce customers, LMS students, members and form leads into more than thirty email marketing platforms and CRMs. It is primarily an API **consumer**, not an API producer: the plugin runs self-hosted inside the customer's WordPress installation and registers no REST routes of its own. Its one first-party HTTP surface is a hosted OAuth broker at auth.fusewp.com that holds FuseWP's OAuth client credentials and performs the authorization-code and refresh-token exchange for the eleven partner platforms that require OAuth.

## What FuseWP is and is not

- No public REST API. Zero `register_rest_route` calls in the shipped plugin (fusewp 1.1.26.1). Nothing to call on a site that has FuseWP installed.
- No OpenAPI, no GraphQL, no AsyncAPI, no webhooks, no agent card.
- The developer extension surface is in-process PHP actions and filters, not HTTP. See conventions/fusewp-conventions.yml.
- One first-party HTTP service: the OAuth broker at https://auth.fusewp.com, undocumented, discovered from the GPL plugin source and confirmed by live probe.
- One MCP endpoint, served by the WordPress MCP Adapter on fusewp.com and advertised through RFC 9728. OAuth-gated; anonymous `tools/list` returns 401.

## APIs

- [FuseWP OAuth Broker](https://auth.fusewp.com): GET /{integration_id} starts a partner authorization (302 to the partner's own authorize endpoint); GET /{integration_id}?refresh_token={token} refreshes and returns a JSON `success` envelope. Live integration ids: aweber, birdsend, campaignmonitor, constantcontact, copper, gohl, hubspot, keap, mailchimp, zohocrm, zohocampaigns.
- [MCP server](https://fusewp.com/wp-json/mcp/mcp-oauth-server): OAuth-protected, scope `mcp`, PKCE S256. Tool list not observable anonymously.
